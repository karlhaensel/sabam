# sabam
Look at, measure, and draw cool things with interactive map.

This is supposed to be a PWA (Progressive Web App).

So it's time to say: GO, GO, GOOO!

## Develop/test the current version
1. clone this repo
2. start local web server
3. run locally in browser
4. debug with devtools (F12)

For example, if you are using `vscode`, install the extension "Live Server", right-click on `index.html` and choose "Open with Live Server".
